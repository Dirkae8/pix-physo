# PIXPHYSO — Реалистичная Физическая Песочница (GPU + CPU)

Многофизическая пиксельная песочница в духе **The Powder Toy** с современной шейдерной графикой **WebGL2 PBR + HDR Bloom**, термодинамикой, гидростатикой сообщающихся сосудов, аэродинамикой Навье–Стокса, электротехникой, химией и ядерной физикой.

## Быстрый запуск без установки (Готовая сборка)
1. Скачайте готовый архив **[`PIXPHYSO-Release.zip`](./PIXPHYSO-Release.zip)** (или одиночный файл **[`PIXPHYSO.html`](./PIXPHYSO.html)**).
2. На **Windows** распакуйте архив и дважды нажмите **`START_PIXPHYSO.bat`** — игра сразу откроется в отдельном окне с аппаратным ускорением видеокарты (`WebGL2 GPU`), ничего устанавливать не нужно.
3. На любой ОС (**Windows / macOS / Linux / Android**) можно просто открыть **`PIXPHYSO.html`** двойным кликом в любом современном браузере — работает полностью офлайн.

## Ключевые особенности
- **Гибридный вычислительный конвейер GPU + CPU**:
  - **90% GPU / 10% CPU (по умолчанию)** — многопроходный WebGL2 FBO-решатель объёмного излучения, теплового поля, PBR-микротекстур материалов, преломления стекла, излучения абсолютно чёрного тела (кривая Планка) и HDR Bloom.
  - **70% GPU / 30% CPU (режим «Баланс» в Настройках)** — переносит дополнительные итерации аэродинамики, электроцепей и теплопроводности на типизированные массивы процессора.
- **68 интерактивных веществ, устройств и инструментов** (+ 11 промежуточных фазовых состояний):
  - **Твёрдые и стены**: Кирпич, Дерево, Сталь, Стекло, Титан, Бетон, Лёд, Губка, Резина, Керамика, Парафин, Свинец.
  - **Сыпучие**: Песок, Земля, Соль, Сахар, Уголь, Снег, Опилки, Цемент, Натрий, Золото, Железная стружка.
  - **Жидкости**: Вода, Ртуть, Лава, Моторное масло, Нефть, Бензин, Кислота, Жидкий азот, Спирт, Мёд, Нитроглицерин.
  - **Газы**: Водород, Метан, Пропан, Ацетилен, Кислород, Пар, Дым, Углекислый газ, Хлор.
  - **Электрика и обдув**: Медный провод, Кабель в изоляции, Аккумулятор (24 В), Генератор (48 В), Кнопка, Тумблер ВКЛ/ВЫКЛ, Турбинный вентилятор (4 направления), Нихром (ТЭН), Лампа LED, Катушка Тесла, Электродетонатор.
  - **Взрывчатка и атом**: Порох, Тротил (TNT), Пластит C-4, Термит (2500 °C), Напалм, Уран-235, Нейтроны.
  - **Стихии и инструменты**: Огонь, Разряд энергии (плазма/молния), **Рука (захват, отрыв с трещинами и бросок кусков пикселей)**, Нагрев (лазер), Охлаждение, Импульс ветра, Ластик.

## Запуск
```bash
npm install
npm run dev      # Запуск dev-сервера (0.0.0.0:5173)
npm test         # Автоматические тесты законов физики
npm run build    # Сборка production-бандла
```
