# PIXPHYSO

Пиксельная физическая песочница с автономным HTML, графикой WebGL2 и моделями веществ, тепла, воздуха и электричества.

## Готовые файлы

- [PIXPHYSO-Release.zip](./PIXPHYSO-Release.zip) — все варианты запуска.
- [PIXPHYSO.exe](./PIXPHYSO.exe) — Windows x64. Распаковывает встроенную страницу во временную папку и запускает её через Microsoft Edge; если Edge не найден, использует браузер по умолчанию. Требуется современный браузер с WebGL2.
- [PIXPHYSO.apk](./PIXPHYSO.apk) — Android 6.0 и новее, локальный WebView, без сетевых разрешений. Требуется поддержка WebGL2 в системном Android WebView. APK подписан самостоятельным ключом; Android может запросить разрешение на установку из этого источника.
- [PIXPHYSO.html](./PIXPHYSO.html) — автономный файл для современного браузера, работает без сервера и интернета.

Подпись APK самоподписанная, а EXE не имеет доверенной цифровой подписи: системные предупреждения при установке или запуске возможны. Нативный запуск на реальных Windows и Android устройствах в этой среде не проверялся.

## Управление

- Выберите материал или инструмент в нижней панели и рисуйте мышью или касанием. Категории находятся справа/снизу.
- Выберите **«Контроллер»** и нажмите на точку поля. Панель показывает текущие данные именно этой клетки и ищет для подписи ближайшее свободное место; стрелка указывает на клетку. Повторное нажатие рядом удаляет контроллер. Очистка поля и смена разрешения удаляют контроллеры.
- Колёсико меняет размер кисти, правая кнопка стирает, Shift рисует линию, пробел ставит симуляцию на паузу. На телефоне кнопка «Среда» открывает параметры среды.
- Доступно 105 предметов: по 15 в каждой из семи категорий, включая новые инструменты и вещества. Для некоторых новых веществ используются **приближённые общие модели фаз**, а не полная индивидуальная химия.

## Архитектура и ограничения

Физические решатели выполняются на **CPU**, а визуализация и эффекты — на **GPU через WebGL2**. Режим «Баланс» увеличивает количество CPU-итераций; доли нагрузки 90/10 и 70/30 не реализованы и не измеряются. Модели физики являются приближениями, а не научным симулятором.

## Разработка и сборка

```bash
npm ci
npm test
npm run build
npm run dev
npm run build:release # HTML и архив без нативных файлов
```

Для нативных пакетов сначала соберите HTML, затем выполните `scripts/build-windows.sh` (нужен Python с `ziglang`, `ZIG_PYTHON`) и `scripts/build-android.sh` (JRE/keytool, apktool и apksigner, переменные указаны в скрипте). Используйте собственное постоянное приватное хранилище подписи Android. Для обновления приложения нужен тот же ключ; потеря ключа требует удаления старой версии перед установкой. Приватный ключ в репозиторий не входит. После сборки оба пакета можно добавить в архив `zip -j PIXPHYSO-Release.zip PIXPHYSO.exe PIXPHYSO.apk`.
