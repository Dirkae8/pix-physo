# PIXPHYSO

Пиксельная физическая песочница с автономным HTML, графикой WebGL2 и моделями веществ, тепла, воздуха и электричества.

## Готовые файлы

- [PIXPHYSO-Release.zip](./PIXPHYSO-Release.zip) — все варианты запуска.
- [PIXPHYSO.exe](./PIXPHYSO.exe) — Windows x64. Отдельное окно приложения, страница встроена в EXE; браузерное окно не запускается. Нужен установленный Microsoft Edge WebView2 Runtime с поддержкой WebGL2 (обычно уже установлен в Windows 10/11).
- [PIXPHYSO.apk](./PIXPHYSO.apk) — Android 6.0 и новее, локальный WebView, без сетевых разрешений. Требуется поддержка WebGL2 в системном Android WebView. APK подписан самостоятельным ключом; Android может запросить разрешение на установку из этого источника.
- [PIXPHYSO.html](./PIXPHYSO.html) — автономный файл для современного браузера, работает без сервера и интернета.

Подпись APK самоподписанная, а EXE не имеет доверенной цифровой подписи: системные предупреждения при установке или запуске возможны. **В этой версии APK подписан новым постоянным ключом**, так как исходный ключ был утерян: перед установкой удалите предыдущую версию приложения. Нативный запуск на реальных Windows и Android устройствах в этой среде не проверялся.

## Управление

- Выберите материал или инструмент в нижней панели и рисуйте мышью или касанием. Категории находятся справа/снизу.
- Выберите **«Контроллер»** и нажмите на точку поля. Панель показывает текущие данные именно этой клетки и ищет для подписи ближайшее свободное место; стрелка указывает на клетку. Повторное нажатие рядом удаляет контроллер. Очистка поля и смена разрешения удаляют контроллеры.
- Колёсико меняет размер кисти, правая кнопка стирает, Shift рисует линию, пробел ставит симуляцию на паузу. Горячие клавиши: `F` — один шаг физики, `Ctrl+Z` — отмена, `R` — направление вентилятора/насоса/диода, `N` — показать только новинки, `0–7` — быстрый выбор категории. Клавиши не перехватываются, пока фокус находится в текстовом поле, списке или открытом окне. На телефоне кнопка «Среда» открывает параметры среды; выбор предметов прокручивается, а в альбомной ориентации расположен справа. Настройки GPU и меню выхода на телефоне скрыты.
- Доступен **221 предмет**: 121 исходный и **100 новых**, распределённых по всем категориям (24 твёрдых, 16 сыпучих, 20 жидкостей, 16 газов, 10 электрических компонентов, 10 взрывчатых веществ, 4 инструмента). У каждого новые справочные плотность, теплоёмкость, теплопроводность, температуры фазовых переходов, горючесть и прочность; в подсказке и строке выбранного предмета эти данные видны. Кнопка «+100 новых» (клавиша `N`) оставляет в каталоге только новинки. Часть моделей — **приближённые общие модели фаз**, а не полная индивидуальная химия каждого вещества.
- Среди новых предметов: фитиль, пластик ABS, ПВХ, полиэтилен, кевлар, бумага, картон, пенопласт, куриный бульон, «сухая вода», растительное и оливковое масло, молоко, уксус, 10 новых взрывчатых веществ, пьезоэлемент, термопара, магнит, пылесос, молот и сушилка. Фитиль капиллярами тянет масло и керосин, «сухая вода» отдаёт воду при нагреве, сода с уксусом выделяет CO₂, а пьезоэлемент вырабатывает напряжение от нагрузки.

- «Выделить схему» позволяет сохранить прямоугольный фрагмент через меню «Миры» и вставлять его повторно. Там же находятся локальные слоты мира и краткая справка; данные сохраняются во внутреннем хранилище приложения.
- При размещении вентилятора, диода и других направленных устройств задайте направление стрелками. Вентилятор и насос требуют питания; двумя пальцами можно масштабировать и перемещать вид.

Полный перечень готовых механизмов и незавершённых функций — в [UPDATE-NOTES.md](./UPDATE-NOTES.md).

## Архитектура и ограничения

Теплопроводность ограничена для устойчивости; спирт образует собственный пар без взрывов от каждой клетки. Тонкие стены закрывают ячейки воздуха, ветер вводится через открытые границы, а вентиляторы воздействуют на огонь и дым. Сетка воздуха имеет шаг 4×4 пикселя, поэтому узкие проходы могут перекрываться приближённо.

Исправления физики этой версии: сообщающиеся сосуды больше не блокируются глобальным перепадом давления, перенос жидкости не залипает на одной клетке-доноре, буферы поверхностей масштабируются под мир 960×540, жидкость растекается на несколько клеток за такт и корректно обменивается с более лёгкой жидкостью; вода при атмосферном давлении кипит с учётом скрытой теплоты, а в режиме «Баланс» фазовые переходы выполняются один раз за такт, а не дважды. Водные жидкости гасят огонь, а масла — нет.

Оптимизация без потери качества: метки поколений вместо полной очистки массива посещённых ячеек на каждом подшаге, плоские LUT вместо обращений к объектам определений в горячих циклах химии и теплопроводности, отсутствие аллокаций замыканий в BFS цепей, `sqrt` вместо `hypot` во внутренних циклах, однократный расчёт геометрии ударной волны, отложенная генерация миниатюр и освобождение старых GPU-ресурсов при смене разрешения. Сборка релиза больше не требует системной утилиты `zip`.

Каталог материалов рассчитан на 256 ячеек (`MAX_MAT_ID`): `0..144` — исходные вещества, `145..244` — 100 новых предметов, `245..250` — скрытые продукты реакций. Поле мира хранит id в `Uint8Array`, поэтому **255 — жёсткий предел** для любого будущего вещества. Старые сохранения совместимы; при загрузке проверяется, что id вещества существует в текущей таблице.

Физические решатели выполняются на **CPU**, а визуализация и эффекты — на **GPU через WebGL2**. Режим «Баланс» увеличивает количество CPU-итераций; доли нагрузки 90/10 и 70/30 не реализованы и не измеряются. Модели физики являются приближениями, а не научным симулятором.

## Разработка и сборка

```bash
npm ci
npm test                 # 68 тестов, один воркер — стабильно в песочницах с ограниченным TEMP
npm run build            # tsc + vite
npm run dev
npm run build:release    # PIXPHYSO.html + PIXPHYSO-Release.zip, без внешнего zip
```

Для нативных пакетов сначала соберите HTML, затем выполните `scripts/build-windows.sh` (нужен Python с `ziglang`, `ZIG_PYTHON`, а также `WEBVIEW2_INCLUDE` с заголовком `WebView2.h` из Microsoft WebView2 SDK; для примера он также имеется в npm-пакете `webview-node@0.1.5` в `bin/source/include`) и `scripts/build-android.sh` (JRE/keytool, apktool и apksigner, переменные указаны в скрипте). Текущий приватный ключ хранится вне репозитория (`~/.android/pixphyso-release.keystore`), пароль в документацию не включается. Для обновления приложения нужен тот же ключ; потеря ключа требует удаления старой версии перед установкой. После сборки оба пакета можно добавить в архив общим скриптом `scripts/build-native-release.sh`.

Тесты: `npm test` проверяет тепло и горение, запертые воздушные потоки и вентиляцию через отверстия, отклонение огня вентилятором, гидростатику, электроцепи, новый каталог из 100 предметов, реакции новых веществ, новые инструменты и скорость кипения воды. На Windows и Android фактический запуск пакетов требует проверки на устройстве.
